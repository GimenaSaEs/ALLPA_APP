# Manual de usuario (estado parcial)

La versión actual no integra los módulos ALLPA desde el punto de entrada, por lo que no existe aún un recorrido de usuario verificable. Para compilar/abrir el proyecto, consulte el manual técnico; se mostrará la plantilla de Flutter.

Cuando se integre la navegación, el recorrido esperado deberá ser: completar perfil; registrar terreno y área; asociar cultivo y plan; registrar labores e insumos con fecha; consultar bitácora; registrar cosecha y revisar indicadores/exportaciones. Validar el flujo primero con datos ficticios. No ingresar datos personales reales durante pruebas ni publicar la base local.
